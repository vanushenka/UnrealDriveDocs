# Offset Mode

```{note}
This is the **Offset** tile in the **Edit** palette of the Meta Road editor mode
(see [The Meta Road Editor Mode](/editor-mode/MetaRoadEditorMode.md)).
```

![Offset sub-mode active in the Meta Road palette](/img/offset-mode.png)

**Offset Mode** sets the **center-line** offset relative to the
[Road Reference Line](/concepts/RoadModel.md#road-reference-line) — this is the
[Lane Offset](/concepts/RoadModel.md#lane-offset) of the road model. You edit the offset curve just like a spline: set
any shape, add/delete nodes, and edit tangents.

![Editing the center-line offset curve](/img/offset.gif)

## Selection

In the **Details** panel, the **Selection** group edits the selected **Offset Key**:

![The Details Selection group for a selected Offset Key](/img/offset-mode-selection.png)
