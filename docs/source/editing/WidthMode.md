# Width Mode

```{note}
This is the **Width** tile in the **Edit** palette of the Meta Road editor mode
(see [The Meta Road Editor Mode](/editor-mode/MetaRoadEditorMode.md)).
```

![Width sub-mode active in the Meta Road palette](/img/width-mode.png)

**Width Mode** edits the width of a **Road Lane** along the road. You edit the width curve just like a spline: set any
shape, add/delete nodes, and edit tangents.

![Editing a lane's width curve along the road](/img/width.gif)

## Selection

In the **Details** panel, the **Selection** group edits the selected **Width Key**:

![The Details Selection group for a selected Width Key](/img/width-selection.png)
