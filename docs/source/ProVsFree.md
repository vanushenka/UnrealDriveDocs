# Pro vs Free

The Pro version includes all the functionality of the Free version + additional features:
  - [Tool for quickly generating typical intersections](NewIntersectionTool.md) 
  - [Tool for creation of pedestrian crossings](DrawCrosswalkTool.md) 
  - [ZoneGraph generation](ZoneGraph.md) 
  - [Supporting of Landscape](Landscape.md) and [Supporting of Landscape Attribute](AttributeModes.md#landscape-attribute-pro)
  - [Curb Cut attribute](AttributeModes.md#curb-cut-attribute-pro)
  - [Polygon attribute (for example, for task for drawing road arrows)](AttributeModes.md#polygon-attribute-pro) and [Polygon profile](Presets.md#polygon-profile-pro)
